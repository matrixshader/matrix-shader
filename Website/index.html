Installation in 2 Minutes

Simple setup for instant Matrix effects

1

Install

Run this one-liner in PowerShell:

irm https://matrixshader.com/install.ps1 | iex

Or download the installer from GitHub Releases.

2

Choose Your Path

Take the Blue Pill for automatic setup, or the Red Pill for full control.

wakeupneo.exe
3

Customize & Control

Use redpill.exe for the control panel with hotkeys, color presets, and layout modes.

System Requirements

  • ✅ Windows 10/11
  • ✅ Windows Terminal (installed from Microsoft Store)
  • ✅ GPU with HLSL support (virtually all modern GPUs)
  • ✅ .NET 8 Runtime (included in installer)
