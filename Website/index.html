Installation in 2 Minutes

Simple setup for instant Matrix effects

1

Download Matrix Shader

Get the latest release from GitHub or use the direct download below.

2

Configure Windows Terminal

Add one line to your settings.json to enable pixel shaders.

"experimental.pixelShaderPath": "C:\\Matrix\\shaders\\Matrix-1.hlsl"
3

Launch & Customize

Run wakeupneo.exe for the setup wizard or redpill.exe for the control panel.
