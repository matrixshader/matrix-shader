  <action>
Run the full build process to compile all executables with Phase 13 fixes.

1. Build all CLI projects:
```powershell
cd MatrixShader/src/MatrixShader.Cli/WakeupNeo
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishTrimmed=true

cd ../Bluepill
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishTrimmed=true

cd ../Redpill
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishTrimmed=true

cd ../MatrixLite
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishTrimmed=true
```

2. Build monitor and hotkeys:
```powershell
cd ../../MatrixShader.Monitor
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishTrimmed=true

cd ../MatrixShader.Hotkeys
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishTrimmed=true
```

3. Copy executables and shaders to installer/publish:
```powershell
cd ../../../installer
mkdir -Force publish
mkdir -Force publish/shaders

# Copy executables
Copy-Item ..\MatrixShader\src\MatrixShader.Cli\WakeupNeo\bin\Release\net8.0\win-x64\publish\*.exe publish\
Copy-Item ..\MatrixShader\src\MatrixShader.Cli\Bluepill\bin\Release\net8.0\win-x64\publish\*.exe publish\
Copy-Item ..\MatrixShader\src\MatrixShader.Cli\Redpill\bin\Release\net8.0\win-x64\publish\*.exe publish\
Copy-Item ..\MatrixShader\src\MatrixShader.Cli\MatrixLite\bin\Release\net8.0\win-x64\publish\*.exe publish\
Copy-Item ..\MatrixShader\src\MatrixShader.Monitor\bin\Release\net8.0\win-x64\publish\*.exe publish\
Copy-Item ..\MatrixShader\src\MatrixShader.Hotkeys\bin\Release\net8.0\win-x64\publish\*.exe publish\

# Copy shaders (with Phase 13 fixes)
Copy-Item ..\shaders\*.hlsl publish\shaders\
```

4. Run Inno Setup to build installer:
```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" MatrixShaderSetup.iss
```

5. Verify installer was created:
```powershell
Get-Item output\MatrixShaderSetup.exe | Format-List Name, Length, LastWriteTime
```
