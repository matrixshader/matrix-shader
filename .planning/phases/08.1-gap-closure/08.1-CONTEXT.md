### Package Cleanup (GAP-C03)

### Documentation Sync (GAP-C04)
- Full verification of REQUIREMENTS.md statuses against actual implementation
- Update CLI-02, CLI-03, UX-02 to Complete

### Transparency/Opacity (GAP-I01)
- Fix now: B key toggles transparency, K/L adjust opacity

### Tab Color Sync (GAP-I03)
- Implement now: Sync Windows Terminal tab colors to match shader RGB
- Update tabColor property in settings.json when shader saved

### AOT Preparation (GAP-I05, GAP-I06)
- Convert 3 DllImport functions to LibraryImport in WindowsApi.cs:

  - GetMonitorInfo

### GetActiveSlots Fix (GAP-I10)
- Fix WakeupNeo to use ShaderExists check instead of color comparison
- Match Bluepill's correct approach
- Ensures default green slots aren't incorrectly excluded

### Monitor Service (GAP-I04)
- Implement now: Start MatrixShader.Monitor from Bluepill after session restore
- Hidden background process for drag-snap window rearrangement

### Dev Path Cleanup (GAP-M01)
- Remove hardcoded 'C:\Users\ehome\Documents\Matrix\shaders' fallback
- Rely only on standard locations (AppData, application directory)
