# Phase 08.1 Plan 03: Settings Integration Summary

> **One-liner:** Transparency/opacity and tab color changes now persist to Windows Terminal settings.json via ITerminalSettingsService integration.

## What Was Built

### Task 1: Opacity Application to Settings.json
- Added `ITerminalSettingsService` registration to DI container in `ConfigureServices`
- Added `ITerminalSettingsService` dependency to `ControlPanel` constructor
- Updated `TransparencyToggle` handler to call `ApplyOpacityToProfile`
- Updated `OpacityDecrease`/`OpacityIncrease` handlers to apply changes
- Added `ApplyOpacityToProfile` method that:
  - Loads current settings
  - Gets profile by name (`Matrix-{slot}`)
  - Updates profile opacity
  - Saves settings back to settings.json

### Task 2: Tab Color Sync on Save
- Added `ITerminalSettingsService` dependency to `TabManager` constructor
- Added `SyncTabColorToShader` method that:
  - Converts float RGB (0-1) to hex color (#RRGGBB)
  - Updates profile `TabColor` property
  - Saves settings back to settings.json
- Updated `SaveCurrentShader` to call `SyncTabColorToShader` after writing shader

### Task 3: DI Verification
- Verified `ITerminalSettingsService` registration resolves correctly
- Both `ControlPanel` and `TabManager` receive the service via constructor injection
- Full solution builds successfully

## Key Implementation Details

### Opacity Flow
```
B key -> TransparencyToggle -> ApplyOpacityToProfile(100 or _opacity)
K key -> OpacityDecrease   -> ApplyOpacityToProfile(_opacity - 5)
L key -> OpacityIncrease   -> ApplyOpacityToProfile(_opacity + 5)
```

### Tab Color Format
```csharp
// Float RGB (0-1) to hex (#RRGGBB)
var r = (int)(config.R * 255);
var g = (int)(config.G * 255);
var b = (int)(config.B * 255);
var hexColor = $"#{r:X2}{g:X2}{b:X2}";
```

### Error Handling
- Opacity application: Logs warning on failure, continues operation
- Tab color sync: Silent failure with diagnostic logging (nice-to-have feature)
