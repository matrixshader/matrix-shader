# Phase 10.5 Plan 03: Hotkey Actions and Toast Notifications Summary

All 12 hotkey action handlers implemented with full service integration, plus toast notifications for conflict warnings.

## What Was Built

### 1. UseAcrylic Property (TerminalProfile.cs)
Added `UseAcrylic` property to TerminalProfile for transparency toggle support. This property maps to Windows Terminal's acrylic transparency effect.

### 2. HotkeyActions Class (482 lines)
Complete implementation of all 12 hotkey action handlers:

**Window Actions:**
- `SwapLeft` / `SwapRight`: Uses IdentityService.FindMatrixWindows() and WindowsApi.PositionWindowExact() to swap focused window with neighbor
- `CycleLayout`: Uses ConfigService and LayoutService to cycle through Pillars -> Quads -> Overlap -> Auto

**Terminal Settings Actions:**
- `ToggleTransparency`: Uses TerminalSettingsService to toggle UseAcrylic on focused window's profile
- `OpacityUp` / `OpacityDown`: Adjusts Opacity +/- 5%, clamped to 0-100
- `CycleShader`: Cycles PixelShaderPath through Matrix-1 to Matrix-8

**Shader Actions:**
- `SpeedUp` / `SpeedDown`: Adjusts RAIN_SPEED +/- 0.1, clamped to 0.1-3.0
- `ToggleFar` / `ToggleMid` / `ToggleNear`: Toggles SHOW_L1/L2/L3 layer visibility

All actions:
- Use dependency injection for services
- Fail silently on errors (per CONTEXT.md requirement)
- Target the currently focused Matrix window

### 3. ToastNotifications Class (128 lines)
Toast notification support for conflict warnings:
- `ShowConflictWarning(IReadOnlyList<FailedHotkey>)`: Shows Windows toast with failed hotkey list (up to 5), directs user to Redpill
- `ShowInfo(title, message)`: Simple informational toast
- `Cleanup()`: Uninstalls AUMID for non-packaged apps
- `IsSupported()`: Checks if system supports toasts
