1. RegisterHotKey(nint hWnd, int id, uint fsModifiers, uint vk) -> bool
2. UnregisterHotKey(nint hWnd, int id) -> bool
3. GetMessageW(out MSG lpMsg, nint hWnd, uint wMsgFilterMin, uint wMsgFilterMax) -> bool
4. DispatchMessageW(ref MSG lpMsg) -> nint
5. PostQuitMessage(int nExitCode) -> void
6. CreateWindowExW for message-only window creation
7. DefWindowProcW for window procedure
8. RegisterClassExW for window class registration

- Modifiers: MOD_ALT (0x0001), MOD_CONTROL (0x0002), MOD_SHIFT (0x0004), MOD_WIN (0x0008), MOD_NOREPEAT (0x4000)
- Messages: WM_HOTKEY (0x0312), WM_DESTROY (0x0002)
- Virtual keys: VK_LEFT (0x25), VK_RIGHT (0x27), VK_UP (0x26), VK_DOWN (0x28), VK_1-VK_3 (0x31-0x33), VK_B (0x42), VK_J (0x4A), VK_K (0x4B), VK_L (0x4C), VK_S (0x53)

Include MSG struct with LayoutKind.Sequential for message loop.

Follow WindowsApi.cs patterns exactly for consistency (partial class, regions, XML docs).
