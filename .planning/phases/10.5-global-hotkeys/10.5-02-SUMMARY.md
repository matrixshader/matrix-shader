### 2. HotkeyWindow (Message-Only Window)
Pattern: Creates invisible window using `HWND_MESSAGE` as parent.

```csharp
// Creates window that only receives messages (no visible UI)
_hWnd = HotkeyApi.CreateWindowExW(
    0, ClassName, "Matrix Hotkeys", 0,
    0, 0, 0, 0,
    HotkeyApi.HWND_MESSAGE,  // Key: message-only parent
    nint.Zero, _hInstance, nint.Zero);
```

**Critical GC Prevention:**
```csharp
// Store delegate as field to prevent GC collection during window lifetime
private readonly HotkeyApi.WNDPROC _wndProcDelegate;

public HotkeyWindow()
{
    _wndProcDelegate = WndProc;  // Pin delegate
}
```

**Thread-Safe Stop:**
```csharp
public void Stop()
{
    _running = false;
    if (_hWnd != nint.Zero)
        HotkeyApi.PostQuitMessage(0);  // Posts to message queue
}
```

### 3. HotkeyManager (Registration Lifecycle)
Manages hotkey registration with conflict tracking.

```csharp
public int RegisterHotkey(uint modifiers, uint vk, string actionName)
{
    // Always include MOD_NOREPEAT to prevent auto-repeat
    uint effectiveModifiers = modifiers | HotkeyApi.MOD_NOREPEAT;

    bool success = HotkeyApi.RegisterHotKey(_hWnd, id, effectiveModifiers, vk);

    if (!success)
    {
        int error = Marshal.GetLastWin32Error();
        _failedHotkeys.Add(new FailedHotkey(...));
    }
}
```

**Error Tracking:**
- `GetRegisteredHotkeys()` - Successfully registered hotkeys
- `GetFailedHotkeys()` - Hotkeys that failed (with error codes)
- Error 1409: "Already registered by another application"

### 4. SingleInstance (Mutex Enforcement)
Prevents duplicate matrix-hotkeys processes.

```csharp
// Global prefix for cross-session visibility (Remote Desktop, multiple users)
private const string MutexName =
    @"Global\{B8C3F9A2-7D4E-4A1B-9C6D-3E8F5A2B1C0D}-MatrixHotkeys";
```

**Handles edge cases:**
- `createdNew = false` - Another instance running
- `AbandonedMutexException` - Previous instance crashed
- `UnauthorizedAccessException` - Elevated process holds mutex

## Architecture

```
Program.Main()
    |
    +-- SingleInstance.TryAcquire() -> Exit if false
    |
    +-- HotkeyWindow.Create()
    |       |
    |       +-- RegisterClassExW(wndProc stored in field)
    |       |
    |       +-- CreateWindowExW(HWND_MESSAGE parent)
    |
    +-- HotkeyManager.RegisterHotkey() (for each configured hotkey)
    |       |
    |       +-- RegisterHotKey(hWnd, id, modifiers | MOD_NOREPEAT, vk)
    |
    +-- HotkeyWindow.RunMessageLoop() [blocks]
            |
            +-- GetMessageW() [receives WM_HOTKEY]
            |
            +-- WndProc() -> HotkeyPressed event
```
