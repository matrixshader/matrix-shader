    Add a private method to detect and handle terminal resize:

    ```csharp
    /// <summary>
    /// Checks if the terminal has been resized and reinitializes if needed.
    /// </summary>
    /// <returns>True if resize occurred and reinitialization was needed</returns>
    private bool CheckAndHandleResize()
    {
        try
        {
            int newWidth = Console.WindowWidth;
            int newHeight = Console.WindowHeight;

            if (newWidth != _width || newHeight != _height)
            {
                // Terminal was resized - reinitialize
                Reinitialize(newWidth, newHeight);
                return true;
            }
        }
        catch
        {
            // Console access may fail during resize - ignore
        }
        return false;
    }
    ```

    Also add the Reinitialize helper method:

    ```csharp
    /// <summary>
    /// Reinitializes the renderer for new dimensions.
    /// </summary>
    private void Reinitialize(int newWidth, int newHeight)
    {
        // Update dimensions (need to make them non-readonly or use different approach)
        // Store in local fields that can be modified
        _currentWidth = newWidth;
        _currentHeight = newHeight;

        // Recreate columns array for new width
        _columns = new Column[newWidth];
        for (int x = 0; x < newWidth; x++)
        {
            _columns[x] = new Column(x, newHeight, _random);
            if (_random.NextDouble() > _density)
            {
                _columns[x].Reset();
            }
        }

        // Clear screen for clean redraw
        Console.Write(ClearScreen);
        Console.Write(Home);
    }
    ```

    Note: The _width and _height fields are readonly. Change the class to use mutable _currentWidth and _currentHeight fields instead, initialized from the constructor parameters.
