<task type="auto">
  <name>Task 3: Add input validation to ParseFloat</name>
  <files>MatrixShader/src/MatrixShader.Core/Services/ShaderService.cs</files>
  <action>
The current ParseFloat doesn't validate the regex match value format. A malformed shader file with `#define RAIN_R abc` would cause float.TryParse to fail silently.

Update ParseFloat to validate the matched string is a valid float format before parsing:

```csharp
private static float ParseFloat(string content, Regex regex, float defaultValue)
{
    var match = regex.Match(content);
    if (match.Success)
    {
        var valueStr = match.Groups[1].Value;
        // Validate: must be valid float format (digits, optional decimal point, more digits)
        // Reject patterns like "1.2.3" or "abc" or empty string
        if (System.Text.RegularExpressions.Regex.IsMatch(valueStr, @"^\d+\.?\d*$") &&
            float.TryParse(valueStr, System.Globalization.CultureInfo.InvariantCulture, out var value))
        {
            return value;
        }
    }
    return defaultValue;
}
```

IMPORTANT: Use CultureInfo.InvariantCulture for parsing to avoid locale issues (some locales use comma as decimal separator).
