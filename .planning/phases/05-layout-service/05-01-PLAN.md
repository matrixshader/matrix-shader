1. Add IConfigService constructor parameter:
   ```csharp
   private readonly IConfigService _configService;

   public LayoutService(IConfigService configService)
   {
       _configService = configService;
   }
   ```

2. Implement AdjustGap (immutable pattern matching LayoutConfig record):
   ```csharp
   public LayoutConfig AdjustGap(LayoutConfig current, int delta)
   {
       var newGap = Math.Clamp(current.GapSize + delta, 0, 200);
       return current with { GapSize = newGap };
   }
   ```

   Example AdjustGap -> UpdateConfig call chain from TUI:
   ```csharp
   // User presses +/- key
   var newConfig = layoutService.AdjustGap(currentConfig, +5);
   layoutService.UpdateConfig(newConfig);  // Persists immediately
   ```

3. Implement UpdateConfig with immediate persistence:
   ```csharp
   public void UpdateConfig(LayoutConfig config)
   {
       var state = _configService.LoadState();
       state = state with { Layout = config };
       _configService.SaveState(state);
   }
   ```

4. Update CycleMode to also return string representation for Mode property:
   ```csharp
   public LayoutConfig CycleMode(LayoutConfig current)
   {
       var nextMode = CycleMode(ParseLayoutMode(current.Mode));
       return current with { Mode = nextMode.ToString() };
   }
   ```
   Keep existing CycleMode(LayoutMode) as helper, add overload accepting LayoutConfig.

   **IMPORTANT:** CycleMode is a pure function - it returns new config but does NOT persist.
   The caller (Phase 6 TUI) MUST call UpdateConfig(newConfig) after CycleMode to persist changes.

   Example call chain from TUI:
   ```csharp
   var newConfig = layoutService.CycleMode(currentConfig);
   layoutService.UpdateConfig(newConfig);  // Caller persists
   ```

Context decision: "immediately on any change" for persistence - this is why UpdateConfig calls SaveState directly.
