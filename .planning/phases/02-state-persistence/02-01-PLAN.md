Create new file `MatrixShader/src/MatrixShader.Core/Serialization/MatrixJsonContext.cs`:

```csharp
using System.Text.Json.Serialization;
using MatrixShader.Core.Models;

namespace MatrixShader.Core.Serialization;

/// <summary>
/// Source-generated JSON serializer context for Native AOT compatibility.
/// All JSON serialization must use this context instead of reflection.
/// </summary>
[JsonSourceGenerationOptions(
    WriteIndented = true,
    PropertyNamingPolicy = JsonKnownNamingPolicy.CamelCase,
    UseStringEnumConverter = true,
    DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull)]
[JsonSerializable(typeof(MatrixState))]
[JsonSerializable(typeof(ShaderConfig))]
[JsonSerializable(typeof(LayoutConfig))]
[JsonSerializable(typeof(Dictionary<int, ShaderConfig>))]
internal partial class MatrixJsonContext : JsonSerializerContext
{
}
```

Key points:
- `UseStringEnumConverter = true` handles RenderMode and LayoutMode enums (AOT-safe)
- `PropertyNamingPolicy = JsonKnownNamingPolicy.CamelCase` matches existing JSON format
- `WriteIndented = true` for human-readable config files
- `Dictionary<int, ShaderConfig>` explicitly registered (required for nested collections)
- `internal partial class` - partial is required for source generator
  </action>

Build succeeds with no SYSLIB warnings related to JSON serialization.
