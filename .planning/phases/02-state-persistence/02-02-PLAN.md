  <action>
Update `MatrixShader/src/MatrixShader.Core/Services/ConfigService.cs`:

1. Add import: `using MatrixShader.Core.Serialization;`

2. Remove the static JsonSerializerOptions field (lines 15-20):
   ```csharp
   // DELETE THIS:
   private static readonly JsonSerializerOptions JsonOptions = new()
   {
       WriteIndented = true,
       PropertyNamingPolicy = JsonNamingPolicy.CamelCase,
       Converters = { new JsonStringEnumConverter() }
   };
   ```
   Options are now defined in MatrixJsonContext attributes.

3. Update LoadState() method (around line 53-55):
   Change:
   ```csharp
   var state = JsonSerializer.Deserialize<MatrixState>(json, JsonOptions);
   ```
   To:
   ```csharp
   var state = JsonSerializer.Deserialize(json, MatrixJsonContext.Default.MatrixState);
   ```

4. Update SaveState() method (around line 85-87):
   Change:
   ```csharp
   var json = JsonSerializer.Serialize(state, JsonOptions);
   File.WriteAllText(tempPath, json);
   ```
   To:
   ```csharp
   var json = JsonSerializer.Serialize(state, MatrixJsonContext.Default.MatrixState);
   File.WriteAllText(tempPath, json, new System.Text.UTF8Encoding(false));
   ```
   Using UTF8Encoding(false) for no BOM, matching ShaderService pattern.

5. Add temp file cleanup in catch block of SaveState():
   Change the catch block to:
   ```csharp
   catch (Exception ex)
   {
       _logger.LogError(ex, "Failed to save state to {Path}", StatePath);

       // Clean up temp file on failure
       try
       {
           if (File.Exists(tempPath))
               File.Delete(tempPath);
       }
       catch
       {
           // Ignore cleanup failures
       }

       throw;
   }
   ```

6. Remove unused `using System.Text.Json.Serialization;` if JsonStringEnumConverter is no longer referenced.

Key insight: The project has `JsonSerializerIsReflectionEnabledByDefault=false`, so the old code would fail to compile after Plan 01. This plan makes it compile again.
