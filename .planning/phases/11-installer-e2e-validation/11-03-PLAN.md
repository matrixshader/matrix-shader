<task type="auto">
  <name>Task 1: Add shader copy to LocalAppData during install</name>
  <files>installer/MatrixShaderSetup.iss</files>
  <action>
Add a [Run] section to copy shaders from {app}\shaders to %LOCALAPPDATA%\MatrixShader\shaders:

1. Add after the [Files] section:
   ```ini
   [Run]
   ; Copy shaders to user's LocalAppData for consistent path resolution
   Filename: "cmd.exe"; Parameters: "/c mkdir ""{localappdata}\MatrixShader\shaders"" 2>nul & xcopy ""{app}\shaders\*"" ""{localappdata}\MatrixShader\shaders"" /E /Y /Q"; \
       Flags: runhidden waituntilterminated; StatusMsg: "Setting up shader files..."
   ```

   Alternative using Pascal Script for better error handling (add to [Code] section):
   ```pascal
   procedure CopyShadersToLocalAppData();
   var
     SourceDir, DestDir: String;
     FindRec: TFindRec;
   begin
     SourceDir := ExpandConstant('{app}\shaders');
     DestDir := ExpandConstant('{localappdata}\MatrixShader\shaders');

     if not DirExists(DestDir) then
       ForceDirectories(DestDir);

     // Copy all .hlsl files
     if FindFirst(SourceDir + '\*.hlsl', FindRec) then
     try
       repeat
         FileCopy(SourceDir + '\' + FindRec.Name, DestDir + '\' + FindRec.Name, False);
       until not FindNext(FindRec);
     finally
       FindClose(FindRec);
     end;
   end;
   ```

2. Add to CurStepChanged procedure (or create it if it doesn't exist):
   ```pascal
   procedure CurStepChanged(CurStep: TSetupStep);
   begin
     if CurStep = ssPostInstall then
       CopyShadersToLocalAppData();
   end;
   ```

The CMD approach is simpler and adequate. Choose based on your preference - the CMD version is fewer lines and works reliably.
  </action>
  <verify>Inno Setup syntax appears valid (balanced brackets and semicolons)</verify>
  <done>Installer copies shaders to %LOCALAPPDATA%\MatrixShader\shaders during install</done>
</task>

<task type="auto">
  <name>Task 2: Add uninstall cleanup for LocalAppData</name>
  <files>installer/MatrixShaderSetup.iss</files>
  <action>
Add [UninstallDelete] section to clean up user data on uninstall:

1. Add after [UninstallRegistry]:
   ```ini
   [UninstallDelete]
   ; Clean up LocalAppData files created during installation and runtime
   Type: filesandordirs; Name: "{localappdata}\MatrixShader"
   ```

2. Note: This removes ALL of %LOCALAPPDATA%\MatrixShader including:
   - shaders/ directory
   - identity-registry.json
   - matrix_state.json (if stored here)
   - Any other runtime-created files

3. Optionally, be more selective if user data should persist:
   ```ini
   [UninstallDelete]
   ; Remove shaders (installed files)
   Type: filesandordirs; Name: "{localappdata}\MatrixShader\shaders"
   ; Leave identity-registry.json and matrix_state.json (user data)
   ```

Per CONTEXT.md, we'll use the full cleanup approach - users can always run wakeupneo again if they reinstall.
  </action>
  <verify>Inno Setup syntax appears valid</verify>
  <done>Uninstaller removes %LOCALAPPDATA%\MatrixShader directory</done>
</task>
