  <name>Task 1: Create install.ps1 one-liner script</name>
  <files>installer/install.ps1</files>
  <action>
Create `installer/install.ps1` that enables installation via:
```powershell
irm https://matrixshader.com/install.ps1 | iex
```

The script must:

**1. Detect admin context:**
```powershell
$IsAdmin = ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
```

**2. Set install paths based on context:**
- Admin: `C:\Program Files\MatrixShader\` (system-wide)
- Non-admin: `$env:LOCALAPPDATA\MatrixShader\bin\` (user-only)

**3. Download latest release from GitHub:**
- Use GitHub API to find latest release: `https://api.github.com/repos/matrixshader/matrix-shader/releases/latest`
- Download the release zip (MatrixShader-vX.Y.Z.zip) to temp
- Alternative: Download individual executables if zip not available

**4. Extract and install:**
- Create install directory if not exists
- Extract/copy 6 executables: wakeupneo.exe, bluepill.exe, redpill.exe, matrixlite.exe, matrix-hotkeys.exe, matrix-monitor.exe
- Copy shaders to `$env:LOCALAPPDATA\MatrixShader\shaders\`

**5. Configure PATH:**
- Admin: Add to System PATH via `[Environment]::SetEnvironmentVariable('PATH', ..., 'Machine')`
- Non-admin: Add to User PATH via `[Environment]::SetEnvironmentVariable('PATH', ..., 'User')`
- Check if already in PATH before adding (idempotent)

**6. Update current session:**
- Update `$env:PATH` for immediate use without restarting terminal

**7. Print success message:**
```
Matrix Shader installed successfully!

Next steps:
  1. Open a NEW terminal window (for PATH changes)
  2. Run: wakeupneo

Or try the text-mode demo right now:
  matrixlite
```

**Error handling:**
- Verify GitHub is reachable
- Verify download completed (check file size)
- Verify extraction succeeded
- Clean up temp files on success or failure
- Provide clear error messages on failure

**Idempotency:**
- If already installed, update to latest version
- Don't duplicate PATH entries
- Preserve existing config in LocalAppData

  <name>Task 2: Create uninstall.ps1 script</name>
  <files>installer/uninstall.ps1</files>
  <action>
Create `installer/uninstall.ps1` that cleanly removes Matrix Shader.

The script must:

**1. Detect where installed:**
- Check `C:\Program Files\MatrixShader\` (admin install)
- Check `$env:LOCALAPPDATA\MatrixShader\bin\` (user install)
- Handle case where both exist

**2. Remove executables:**
- Delete the bin/install directory
- Only delete if it contains expected Matrix Shader files (safety check)

**3. Remove user data (optional, with prompt):**
- `$env:LOCALAPPDATA\MatrixShader\` (shaders, config, logs)
- Ask user: "Remove user data? (shaders, config) [y/N]"
- Default to N (preserve data for reinstall)

**4. Remove PATH entries:**
- Remove from User PATH
- Remove from System PATH (if admin)
- Handle multiple entries gracefully

**5. Print completion message:**
```
Matrix Shader uninstalled.

Note: Windows Terminal profiles created by wakeupneo were NOT removed.
To remove them, open Windows Terminal Settings > Profiles.
```

**Error handling:**
- Skip if directory doesn't exist
- Warn but continue if some files locked
- Provide clear status for each step

irm matrixshader.com/uninstall.ps1 | iex
