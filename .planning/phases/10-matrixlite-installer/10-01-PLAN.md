From KatakanaChars.cs:
- KATAKANA constant: half-width Katakana U+FF66..U+FF9D (56 chars)
- DIGITS: "0123456789"
- SYMBOLS: '=*+-<>|:"'
- ALL_CHARS = KATAKANA + DIGITS + SYMBOLS

From ColorPresets.cs (float R, G, B -> byte for ANSI):
- Green:  (0.0, 1.0, 0.3) -> (0, 255, 77)
- Blue:   (0.0, 0.6, 1.0) -> (0, 153, 255)
- Red:    (1.0, 0.1, 0.1) -> (255, 26, 26)
- Purple: (0.7, 0.0, 1.0) -> (179, 0, 255)
- Gold:   (1.0, 0.7, 0.0) -> (255, 179, 0)
- Teal:   (0.0, 0.9, 0.9) -> (0, 230, 230)

From Column.cs:
- __init__(x, max_y): head starts at random(-20, -1), speed 1-3, trail_length 8-25
- update(): tick-based movement, head_y++, trail shift, glitch mutation (1/20 chance)
- brightness(trail_index): (1 - index/length)^1.5 exponential falloff

From TextMatrixRenderer.cs:
- __init__: creates Column per screen column, pre-allocates buffer
- render_frame(): update all columns, respawn inactive (density * 0.1), build ANSI buffer, single stdout.write()
- Head chars: brightness > 1.0 renders as white (255,255,255), trail fades with color * brightness
- check_and_handle_resize(): shutil.get_terminal_size(), reinit if changed

From FallbackMenu.cs:
- Menu mode: show_menu() displays box with options, wait for key
- Animation mode: non-blocking key check with select(), render loop
- Keys: 1-6 color, E/R speed(-/+0.1), D/F density(-/+0.1), Enter fullscreen, B background, Q/ESC quit
- Speed clamped to 0.1-3.0, density clamped to 0.1-1.0
- Ctrl+C returns to menu (signal.SIGINT handler), not exit

From Program.cs:
- --help/-h: show help
- --quiet/-q: skip intro
- --menu/-m: direct to menu
- --rain/-r: direct rain (for scripts)
- Default: intro typewriter -> pill choice (B/R/Q) -> effect/menu -> loop
