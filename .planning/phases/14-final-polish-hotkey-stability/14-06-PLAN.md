<task type="checkpoint:human-verify" gate="blocking">
  <what-built>Built installer with all Phase 14 fixes: hotkey stability, plain transparency, window rotation, layout gaps, shader cycling removal</what-built>
  <how-to-verify>
    **Test in Windows Sandbox:**

    1. Open Windows Sandbox (or fresh Windows VM)

    2. Install Matrix Shader:
       - Run MatrixShader-Setup.exe from shared folder
       - Complete installation

    3. Test hotkey stability (BUG-HK01, BUG-HK04):
       - Run wakeupneo, create 2-4 Matrix windows
       - Test hotkeys (Ctrl+Shift+L for layout, Ctrl+Shift+Up/Down for speed)
       - CLOSE redpill window
       - Wait 10 seconds
       - Test hotkeys again - they should STILL WORK
       - Wait 30+ seconds after closing all Matrix windows
       - Reopen Matrix windows - hotkeys should work immediately

    4. Test transparency (BUG-TRANS04):
       - Matrix windows should show desktop CLEARLY through them
       - NO frosted glass / blurry / hazy appearance
       - Just plain see-through transparency

    5. Test window rotation (BUG-HK02):
       - Focus a Matrix window
       - Press Ctrl+Shift+Right repeatedly
       - Window should rotate through ALL positions (1->2->3->4->1)
       - NOT just swap with adjacent window

    6. Test layer toggles (BUG-HK03):
       - Focus a Matrix window
       - Press Ctrl+Shift+1 - far layer should toggle
       - Press Ctrl+Shift+2 - mid layer should toggle
       - Press Ctrl+Shift+3 - near layer should toggle

    7. Test layout gaps (BUG-LAYOUT05):
       - With 4 pillars, gaps should be at least 20px
       - Should be able to click between windows

    8. Test fullscreen (BUG-LAYOUT06):
       - Focus a Matrix window
       - Press F11 for fullscreen
       - Window should stay fullscreen (not snap back)

    9. Test shader cycling removed (BUG-SHADER04/05):
       - Ctrl+Shift+S should do nothing (hotkey not registered)

    10. Test uninstall restores settings (BUG-TRANS05):
        - Uninstall Matrix Shader
        - Check Windows Terminal settings - should be restored to original

    **Expected results:**
    - All hotkeys work without redpill open
    - Transparency is plain (no blur)
    - Window rotation works across all positions
    - Layer toggles work
    - 4-pillar gaps are clickable
    - Fullscreen stays fullscreen
    - Shader cycling removed
    - Uninstall restores settings
  </how-to-verify>
