<task type="auto">
  <name>Task 2: Launch full test environment with local server and sandbox</name>
  <files>installer/output/, MatrixShaderTest.wsb</files>
  <action>
    This task automates the complete E2E test environment setup:

    1. **Start local HTTP server** on the host machine:
       ```powershell
       # In a new PowerShell window, from installer/output directory:
       cd C:\Users\ehome\Documents\Matrix\installer\output
       python -m http.server 9090
       # Or: npx http-server -p 9090 --cors
       ```

    2. **Get host IP for sandbox** (WSL/Hyper-V network adapter):
       ```powershell
       # Find the vEthernet (WSL) or Hyper-V adapter IP
       $HostIP = (Get-NetIPAddress -AddressFamily IPv4 |
           Where-Object { $_.InterfaceAlias -match 'WSL|Hyper-V|vEthernet' -and $_.IPAddress -notmatch '^169\.' } |
           Select-Object -First 1).IPAddress
       Write-Host "Host IP for sandbox: $HostIP"
       ```

    3. **Update MatrixShaderTest.wsb** with current host IP:
       - The WSB file at project root contains the sandbox configuration
       - Update the IP in the LogonCommand to match current host IP
       - The LogonCommand already handles: dark mode, wallpaper, cmd launch with one-liner

    4. **Launch Windows Sandbox**:
       ```powershell
       # Launch the sandbox (it auto-runs the LogonCommand)
       Start-Process "C:\Users\ehome\Documents\Matrix\MatrixShaderTest.wsb"
       ```

    The sandbox will automatically:
    - Set dark mode (AppsUseLightTheme = 0, SystemUsesLightTheme = 0)
    - Set wallpaper to img19.jpg (dark Windows wallpaper)
    - Restart Explorer to apply theme
    - Open cmd and run: `irm http://{HostIP}:9090/install-local-test.ps1 | iex`

    **Alternative one-liner to start everything from host:**
    ```powershell
    # Start server in background, wait, then launch sandbox
    $job = Start-Job { Set-Location 'C:\Users\ehome\Documents\Matrix\installer\output'; python -m http.server 9090 }
    Start-Sleep -Seconds 2
    Start-Process 'C:\Users\ehome\Documents\Matrix\MatrixShaderTest.wsb'
    Write-Host "Server running (Job ID: $($job.Id)). Stop with: Stop-Job $($job.Id)"
    ```
  </action>
  <verify>
    - HTTP server responds: `curl http://localhost:9090/MatrixShaderSetup.exe -I` returns 200
    - Windows Sandbox launches
    - Sandbox shows dark mode and dark wallpaper
    - Sandbox cmd window opens and runs the one-liner install
  </verify>
  <done>Full test environment running: local server + sandbox with dark mode + one-liner executing</done>
</task>
