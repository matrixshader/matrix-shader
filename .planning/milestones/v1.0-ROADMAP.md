# Milestone v1.0: Matrix Terminal Shader C# Rebuild

**Status:** SHIPPED 2026-01-30
**Phases:** 01-10 (plus 08.1 inserted)
**Total Plans:** 39

## Overview

Complete rebuild of Matrix Terminal Shader from PowerShell to native C#/.NET. The PowerShell version (6,800+ lines) works perfectly - GPU shaders, window controls, monitoring, everything. The C# version replicates this functionality with near-instant startup (<500ms target, achieved ~1000ms cold), then adds MatrixLite text fallback for non-Windows-Terminal environments.

## Milestone Summary

**Decimal Phases:**
- Phase 08.1: Gap Closure (inserted after Phase 08 for critical implementation gaps)

**Key Decisions:**
- Port core functionality before MatrixLite (PowerShell works, MatrixLite-only failed previously)
- Use GSD subagents consistently (context bloat caused previous failure)
- Test in Windows Sandbox (fresh environment catches missing deps)
- Native AOT compilation (instant startup, no runtime required)
- LibraryImport for AOT-compatible P/Invoke (explicit W entry points for Unicode functions)
- Source-generated JSON context for AOT-safe serialization
- 4-layer identity resolution matching PowerShell confidence scoring

**Issues Resolved:**
- Previous C# attempt failed (MatrixLite-only, didn't work anywhere)
- Context bloat during implementation causes lost details (used GSD subagents)
- Startup time goal adjusted: 500ms unrealistic for AOT cold-start, 1000ms acceptable

**Issues Deferred:**
- Monitor service layout recalculation on window move (placeholder)

**Technical Debt Incurred:**
- ConfigService has hardcoded dev path as third fallback (zero impact in production)
