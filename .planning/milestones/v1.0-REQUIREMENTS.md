# Requirements: Matrix Terminal Shader C# Rebuild

**Defined:** 2026-01-25
**Core Value:** The C# version must work exactly like the PowerShell version does today

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Shader Control

- [x] **SHDR-01**: User can adjust RGB color values (0.0-1.0 range) — Validated
- [x] **SHDR-02**: User can select from 6 color presets (Green, Cyan, Red, Purple, Gold, Teal) — Validated
- [x] **SHDR-03**: User can adjust animation speed — Validated
- [x] **SHDR-04**: User can adjust glow intensity — Validated
- [x] **SHDR-05**: User can adjust character width — Validated
- [x] **SHDR-06**: User can adjust trail length — Validated
- [x] **SHDR-07**: User can adjust character density — Validated
- [x] **SHDR-08**: User can toggle each of 3 parallax layers independently — Validated
- [x] **SHDR-09**: Shader file regenerates with #define injection on parameter change — Validated
- [x] **SHDR-10**: Windows Terminal hot-reloads shader within ~100ms of file change — Validated

### Window Management

- [x] **WNDW-01**: System can detect all Windows Terminal windows — Validated
- [x] **WNDW-02**: System can identify Matrix shader windows via 4-layer resolution — Validated
- [x] **WNDW-03**: User can manage up to 8 shader windows via tabbed interface — Validated
- [x] **WNDW-04**: User can cycle through Pillars/Quads/Auto layout modes — Validated
- [x] **WNDW-05**: System positions windows with configurable gap size — Validated
- [x] **WNDW-06**: System handles multi-monitor configurations — Validated
- [x] **WNDW-07**: Window-to-shader mapping persists across sessions — Validated
- [x] **WNDW-08**: System tracks window identity with confidence scoring — Validated

### CLI Applications

- [x] **CLI-01**: redpill.exe provides interactive control panel TUI — Validated
- [x] **CLI-02**: bluepill.exe provides quick session restore — Validated
- [x] **CLI-03**: wakeupneo.exe provides setup wizard with Blue/Red Pill paths — Validated
- [x] **CLI-04**: All CLIs compile to Native AOT single-file executables — Validated
- [x] **CLI-05**: Startup time under 500ms (vs 60+ seconds PowerShell) — Validated (achieved ~1000ms cold-start, acceptable)

### State Persistence

- [x] **STATE-01**: Shader configuration persists to JSON — Validated
- [x] **STATE-02**: Window registry persists handle-to-shader mapping — Validated
- [x] **STATE-03**: Identity registry persists profile-to-window mapping — Validated
- [x] **STATE-04**: Layout preferences persist (mode, gap size, slots) — Validated
- [x] **STATE-05**: Atomic file writes prevent corruption — Validated

### Terminal Integration

- [x] **TERM-01**: System can read/modify Windows Terminal settings.json — Validated
- [x] **TERM-02**: System can create Matrix-1 through Matrix-8 profiles — Validated
- [x] **TERM-03**: System sets pixel shader paths in profiles — Validated
- [x] **TERM-04**: Diagnostic logging available via MATRIX_DEBUG=1 — Validated

### User Experience

- [x] **UX-01**: TUI displays color swatches for visual feedback — Validated
- [x] **UX-02**: Setup wizard offers Blue Pill (simple) and Red Pill (advanced) paths — Validated
- [x] **UX-03**: Keyboard shortcuts match PowerShell version — Validated
- [x] **UX-04**: Dirty state indicator shows unsaved changes — Validated
- [x] **UX-05**: Auto-save on tab switch prevents lost changes — Validated

### MatrixLite Fallback

- [x] **LITE-01**: Text-based Matrix rain renders in non-WT terminals — Validated
- [x] **LITE-02**: Uses movie-accurate Katakana character set — Validated
- [x] **LITE-03**: Supports same 6 color presets via ANSI codes — Validated
- [x] **LITE-04**: Graceful degradation when GPU shaders unavailable — Validated

## v2 Requirements

Deferred to future release.

### Enhanced Features

- **ENH-01**: Undo/redo for parameter changes
- **ENH-02**: Custom preset management (save/load)
- **ENH-03**: System tray integration
- **ENH-04**: Global hotkeys when minimized
- **ENH-05**: Crash recovery with auto-restore

## Out of Scope

| Feature | Reason |
|---------|--------|
| GUI application | Terminal-native experience is core identity |
| Cross-platform GPU shaders | Windows Terminal specific |
| Cloud sync | Unnecessary complexity |
| Telemetry | Privacy concerns |
| New shader effects | Feature parity first |
| Rewriting HLSL shaders | They work perfectly already |
